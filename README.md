# KONOS SUITES — Operations Automation

Système d’automatisation des opérations d’une location saisonnière avec **n8n** et **Notion**.

## Objectif
Automatiser les réservations, interventions, missions, linge, consommables, lessive, annulations, modifications, contrôles avant arrivée, incidents, alertes et reporting.

## Architecture
```text
Plateformes / Gmail → n8n → Notion → Opérations, stocks, alertes et pilotage
```

## Statut
- 16 workflows construits
- 9 workflows testés et publiés
- 7 workflows à tester
